# Uruguay Digital Fácil

Sitio web estático, accesible y responsivo pensado para orientar a personas mayores, extranjeras y usuarios con poca experiencia tecnológica en el uso de servicios digitales de Uruguay.

## Estructura

```text
uruguay-digital-facil/
├── css/
│   └── styles.css
├── pages/
│   ├── ayuda.html
│   ├── nosotros.html
│   ├── noticias.html
│   ├── pagos.html
│   ├── salud.html
│   ├── seguridad.html
│   ├── servicios.html
│   ├── tramites.html
│   ├── transporte.html
│   └── tutoriales.html
├── README.md
└── index.html
```

## Cómo abrirlo

1. Descargá o cloná la carpeta.
2. Abrí `index.html` con Firefox, Chrome, Edge u otro navegador moderno.
3. No requiere instalación, servidor, JavaScript ni dependencias externas.

## Características

- Diseño adaptable a computadora, tableta y celular.
- Navegación semántica y enlace para saltar al contenido.
- Buen contraste, foco visible y botones grandes.
- Respeta la preferencia del usuario de reducir movimientos.
- Impresión optimizada.
- Enlaces externos identificados y abiertos de forma segura.
- Contenido organizado en lenguaje sencillo.

## Nota importante

El sitio es una propuesta educativa y de orientación. Los requisitos, horarios y procedimientos deben verificarse siempre en el portal oficial correspondiente.
